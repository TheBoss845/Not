# Raspberry Pi kiosk

Use a television and hardware you own or have permission to connect.

Build or deploy NOTFLIX, install Chromium on the Pi, set `NOTFLIX_URL`, and launch `scripts/pi/start-notflix.sh` at login. The web app already understands Arrow keys, Enter, Escape, and Backspace. HDMI-CEC support varies by television and Pi image, so any CEC-to-key adapter can be added later without changing the React UI.
